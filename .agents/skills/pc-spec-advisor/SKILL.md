# PC 스펙 어드바이저

사용자의 PC 사용 목적과 예산을 분석하여, 8개 부품 카테고리(CPU, GPU, 메인보드, RAM, SSD, PSU, 케이스, 쿨러)의 타겟 스펙과 예산 배분을 결정한다.

## 용도별 부품 우선순위

| 용도 | 1순위 | 2순위 | 3순위 | 비고 |
|------|-------|-------|-------|------|
| 게임 (FHD) | GPU | CPU | RAM 16GB | CPU는 중급이면 충분 |
| 게임 (QHD/4K) | GPU | CPU | RAM 32GB | GPU 예산 최대화 |
| 개발/프로그래밍 | CPU | RAM 32GB+ | SSD | GPU는 내장/저가 가능 |
| 영상편집 | GPU | CPU | RAM 32GB+ | NVENC/CUDA 활용 |
| 3D 모델링/렌더링 | GPU | RAM 64GB | CPU | VRAM 중요 |
| 사무/일반 | CPU (내장GPU) | SSD | RAM 16GB | 별도 GPU 불필요 |
| 스트리밍 | CPU | GPU | RAM 32GB | 인코딩 성능 중요 |
| AI/딥러닝 | GPU (VRAM) | RAM 64GB+ | CPU | VRAM 24GB+ 권장 |

## 예산 배분 가이드라인

| 총 예산 | CPU | GPU | MB | RAM | SSD | PSU | 케이스 | 쿨러 |
|--------|-----|-----|-----|-----|-----|-----|--------|------|
| 80만 이하 | 25% | 35% | 10% | 10% | 8% | 5% | 4% | 3% |
| 80~150만 | 20% | 40% | 8% | 8% | 8% | 6% | 5% | 5% |
| 150만+ | 18% | 42% | 8% | 7% | 8% | 7% | 5% | 5% |

### 작업용 (CPU 중심)

| 총 예산 | CPU | GPU | MB | RAM | SSD | PSU | 케이스 | 쿨러 |
|--------|-----|-----|-----|-----|-----|-----|--------|------|
| 80만 이하 | 30% | 15% | 12% | 15% | 12% | 6% | 5% | 5% |

이 비율은 가이드라인이다. 사용자의 구체적 요구에 따라 유연하게 조정한다.

## 플랫폼 선택 기준

### Intel vs AMD

- **Intel:** 단일 코어 성능 우세 시 선택. 게임 위주이고 예산 여유 있을 때.
- **AMD:** 멀티코어 가성비 우세 시 선택. 작업용이거나 예산 효율이 중요할 때.
- 사용자 선호가 없으면 현재 세대의 가성비를 비교하여 결정한다.

### DDR4 vs DDR5

- DDR5 플랫폼이 가격 프리미엄 대비 성능 향상이 충분한지 평가한다.
- 예산이 빠듯하면 DDR4 플랫폼이 가성비에 유리할 수 있다.

## 호환성 체크리스트

스펙 타겟 작성 시 반드시 다음을 명시한다:
1. CPU 소켓 (LGA1700, AM5 등)
2. 호환 칩셋 목록
3. RAM 규격 (DDR4/DDR5) 및 최대 지원 속도
4. 폼팩터 (ATX/mATX/ITX)
5. PSU 최소 권장 와트 (GPU TDP 기준 + 여유 30%)

## 예산 부족 시 타협 순서

1. 케이스 → 기능적이면 외관 타협 가능
2. 쿨러 → 번들 쿨러 사용 가능 여부 확인
3. SSD → 용량 축소 (추후 추가 가능)
4. 메인보드 → 하위 칩셋으로 변경 (핵심 기능 유지 조건)
5. RAM → 용량 축소 (추후 추가 가능, 듀얼채널 유지)
6. CPU/GPU → 용도에 따라 한 단계 하향, 이 단계에서는 사용자와 상의
