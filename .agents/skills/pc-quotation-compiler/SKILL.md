# PC 견적 컴파일러

부품 조사 결과를 종합하여 호환성을 검증하고, 3가지 견적(가성비/추천/성능)을 구성한 최종 견적서를 작성한다.

## 호환성 검증 매트릭스

반드시 다음 항목을 모두 검증한다:

| 검증 항목 | 확인 내용 | 불통과 시 조치 |
|----------|----------|--------------|
| CPU ↔ 메인보드 | 소켓 일치, 칩셋 지원 | 메인보드 교체 |
| RAM ↔ 메인보드 | DDR 규격 일치, 속도 지원, 슬롯 수 | RAM 변경 |
| GPU 길이 ↔ 케이스 | GPU 길이 ≤ 케이스 최대 GPU 길이 | 케이스 교체 또는 짧은 GPU |
| 쿨러 높이 ↔ 케이스 | 쿨러 높이 ≤ 케이스 최대 쿨러 높이 | 쿨러 또는 케이스 교체 |
| 쿨러 ↔ CPU | 소켓 호환, TDP 처리 능력 ≥ CPU TDP | 쿨러 교체 |
| PSU 용량 ↔ 시스템 | PSU 와트 ≥ (CPU TDP + GPU TDP) × 1.3 | PSU 교체 |
| 메인보드 폼팩터 ↔ 케이스 | 케이스가 메인보드 폼팩터 지원 | 케이스 교체 |
| SSD ↔ 메인보드 | M.2 슬롯/인터페이스 지원 | SSD 또는 메인보드 변경 |

## 병목 분석 기준

### CPU-GPU 밸런스

- 게임용: CPU와 GPU의 성능 티어가 2단계 이상 차이나면 병목 경고
- 작업용: 용도에 따라 한쪽이 강해도 정상 (예: 렌더링은 GPU 강조 OK)

### RAM 병목

- DDR5 메인보드에 저속 RAM → 성능 손해 경고
- 용량이 용도 대비 부족 → 업그레이드 권고

### 스토리지 병목

- OS/작업 드라이브가 SATA SSD이고 NVMe 슬롯이 비어있으면 → NVMe 권고

## 견적서 작성 규칙

1. **3가지 견적 구성:** 각 카테고리의 가성비/추천/성능 옵션을 조합하되, 견적 내 부품 간 호환성이 보장되어야 한다. 가성비 견적에 성능 GPU를 넣는 식의 불균형 조합은 하지 않는다.

2. **가격 합산:** 모든 부품의 가격을 정확히 합산한다. 예산 대비 차액을 명시한다.

3. **소비전력 계산:** CPU TDP + GPU TDP + 기타(약 50~80W)로 예상 소비전력을 산출한다.

4. **추가 권장사항:** 견적에 포함되지 않았지만 고려할 만한 항목을 안내한다:
   - OS (Windows 라이선스)
   - 모니터 (해상도/주사율 권장)
   - 추가 저장장치
   - 조립비 (셀프 vs 의뢰)

5. **가격 면책:** "가격은 조사 시점 기준이며 변동될 수 있습니다"를 반드시 포함한다.

## 출력 형식

사용자에게 바로 보여줄 수 있는 깔끔한 마크다운 형식으로 작성한다. 기술 용어에는 간단한 설명을 괄호로 병기한다. 전문가가 아닌 사용자도 이해할 수 있는 수준으로 작성한다.
