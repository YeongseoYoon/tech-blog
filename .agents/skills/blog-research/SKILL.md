# Blog Research — 기술 주제 리서치 스킬

기술블로그 포스트를 위한 심층 리서치를 수행한다.

## 리서치 전략

### 1. 주제 분석
사용자의 주제에서 다음을 파악한다:
- 핵심 기술/개념이 무엇인가
- 어떤 카테고리인가 (JavaScript, TypeScript, 브라우저 API, 디자인 패턴, 도구 등)
- 대상 독자의 예상 수준 (초급/중급/고급)

### 2. 조사 순서
1. **공식 문서/스펙** — MDN, TC39 Proposals, W3C Spec, RFC, 공식 GitHub 저장소
2. **배경/역사** — 이 기술이 등장한 이유, 해결하려는 문제, 이전 방식의 한계
3. **핵심 API/패턴** — 주요 기능, 사용법, 파라미터, 반환값
4. **코드 예제** — 기본 사용법 → 실무 활용 패턴 → 엣지 케이스
5. **실무 사례** — 실제 프로젝트에서의 활용 경험, 주의사항, 흔한 실수
6. **비교/대안** — 유사 기술, 라이브러리, 패턴과의 비교

### 3. 출처 관리
- 모든 정보에 출처를 명시한다
- 공식 문서 > 스펙 > 공인된 블로그 > 커뮤니티 순으로 신뢰도를 부여한다
- 출처가 불분명한 정보는 "[미확인]" 태그를 붙인다

## 조사 도구 활용
- **WebSearch**: 최신 동향, 커뮤니티 논의, 블로그 포스트 검색
- **WebFetch**: 공식 문서, 스펙 페이지의 상세 내용 수집
- **Grep/Glob**: 프로젝트 코드베이스에서 관련 코드 패턴 검색 (주제가 프로젝트와 관련된 경우)
