# PC 부품 리서치

스펙 타겟에 맞는 실제 판매 부품을 조사하여 카테고리별 3단 추천(가성비/추천/성능)을 제공한다.

## 조사 방법

### 1. 검색 전략

WebSearch로 다음 패턴의 검색을 수행한다:

```
"{카테고리} 추천 {년도}" — 최신 추천 목록 확인
"{모델명} 최저가 다나와" — 실제 판매가 확인
"{모델명} 벤치마크 리뷰" — 성능 근거 확인
"{모델명} vs {경쟁모델}" — 비교 분석
```

### 2. 가격 소스 우선순위

1. **다나와** (danawa.com) — 국내 최저가 기준 표준
2. **컴퓨존** (compuzone.co.kr) — 조립PC 전문
3. **쿠팡** (coupang.com) — 로켓배송 가격
4. **네이버 쇼핑** — 종합 가격 비교

가격은 항상 출처와 함께 기재한다. 검색 시점의 가격이므로 변동 가능성을 명시한다.

### 3. 카테고리별 핵심 스펙

| 카테고리 | 반드시 기재할 스펙 |
|----------|-------------------|
| CPU | 코어/스레드, 기본/부스트 클럭, TDP, 소켓, 내장GPU 유무 |
| GPU | VRAM, 부스트 클럭, TDP, 길이(mm), 권장 PSU |
| 메인보드 | 칩셋, 소켓, 폼팩터, RAM 슬롯 수, M.2 슬롯 수, Wi-Fi 유무 |
| RAM | 용량, 속도(MHz), 규격(DDR4/5), CL, 개수 |
| SSD | 용량, 인터페이스(NVMe/SATA), 읽기/쓰기 속도, TBW |
| PSU | 와트, 80+ 등급, 모듈러 여부, 팬 크기 |
| 케이스 | 폼팩터 지원, GPU 최대 길이, 쿨러 최대 높이, 팬 구성 |
| 쿨러 | 타입(공랭/수랭), TDP 처리 능력, 높이(mm), 소켓 호환 |

### 4. 추천 등급 기준

- **가성비 (Best Value):** 예산 배분 금액의 80~100% 범위. 가격 대비 성능이 가장 뛰어난 제품.
- **추천 (Recommended):** 예산 배분 금액의 90~110% 범위. 성능·안정성·AS 종합적으로 가장 무난한 제품.
- **성능 (Performance):** 예산 배분 금액의 100~130% 범위. 해당 카테고리에서 확실한 성능 우위 제품.

## 주의사항

- 단종 제품은 추천하지 않는다. 검색 결과에서 "단종", "품절", "판매중지"가 보이면 제외한다.
- OEM/벌크 제품은 AS 불리하므로 정품/박스 제품을 우선한다.
- 리뷰가 극히 적은 신제품은 주의사항에 명시한다.
- 같은 모델의 다양한 제조사 변형(GPU 비레퍼)이 있으면 가성비 좋은 제조사를 추천한다.
